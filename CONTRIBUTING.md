# Contributing

Thanks for wanting to help.

- **Found a bug?** Open an issue with the bug report template. Include your
  Claude Code version and the message the hook printed.
- **Want to propose a change?** Open an issue first and describe the problem
  it solves. Changes that add an exemption from the rule will be declined;
  see "What will not be accepted" in [AGENTS.md](AGENTS.md).
- **Sending a pull request?** [AGENTS.md](AGENTS.md) holds the full rules,
  for people and coding agents alike: how work is done here, the commands to
  run, and what a pull request needs.

By contributing you agree that your work is released under the
[MIT license](LICENSE) and that you will follow the
[code of conduct](CODE_OF_CONDUCT.md).
