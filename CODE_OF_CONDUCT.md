# Code of conduct

This project adopts the Contributor Covenant, version 2.1, as its code of
conduct. The full text is at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.

In short: be respectful, assume good faith, criticise ideas and not people,
and accept that maintainers may edit or remove contributions and comments
that do not meet this standard.

## Reporting

Report unacceptable behaviour to the maintainer through their GitHub
profile, <https://github.com/Malvi1697>. Reports are handled privately.
